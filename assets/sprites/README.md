# Sprites iniciais

`bathroom_atlas.png` é um atlas original gerado para o protótipo. Ele contém personagem, sabonete, pato de borracha, rolo de papel, poça e quatro variações de piso.

As regiões usadas pelo jogo ficam no dicionário `REGIONS`, em `scripts/main.gd`. Isso permite ajustar recortes ou substituir o atlas sem reconstruir a cena inteira.

## Prompt de geração

Atlas transparente 1024×1024 para jogo arcade vertical com personagem de banheiro, sabonete, pato de borracha, rolo de papel, poça e quatro pisos cerâmicos; pixel art moderna, paleta aqua/turquesa/off-white/coral, contornos azul-marinho, objetos isolados, sem texto ou marcas.
